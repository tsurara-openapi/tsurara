# tsurara plugin SDK for Go

Write tsurara plugins in Go (docs/guide/plugins.md). A plugin is a main package that calls `tsuraraplugin.Run`; tsurara runs it once per run:

```yaml
plugins:
  - { module: ./plugin, runtime: [go, -C, ./plugin, run, .] }
```

```go
package main

import (
	tsuraraplugin "github.com/tsurara-openapi/tsurara/packages/plugin-go"
	"github.com/tsurara-openapi/tsurara/packages/plugin-go/protocol"
)

func main() {
	tsuraraplugin.Run(tsuraraplugin.Plugin{
		Name: "functions",
		Extend: func(in protocol.ExtendInput) ([]protocol.OutputFile, error) {
			// in.Manifest.Manifest.Operations, in.Marker, ...
			return nil, nil
		},
	})
}
```

The types of the package `protocol` are generated by tsurara from `spec/plugin-protocol.schema.json`. `NewFile` writes Go files with their imports, formatted with `go/format`. A built binary works as the runtime too (`runtime: [./bin/plugin]`).
