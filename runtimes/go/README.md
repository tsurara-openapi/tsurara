# tsurara runtime for Go

The runtime library for Go code generated by tsurara (`language: go`), module `github.com/tsurara-openapi/tsurara/runtimes/go`, package `tsurara`. Generated functions pass an OperationDef to `tsurara.Do`, which builds the request, sends it through a `Transport` (`net/http` by default), and returns `(*tsurara.Success[T], error)`. It implements the runtime contract in `spec/`, passes its conformance vectors, and uses the standard library only (Go 1.24 or later).

```go
c := tsurara.NewClient("https://api.example.com",
	tsurara.WithHeader("User-Agent", "my-app"),
	tsurara.WithTimeout(10*time.Second),
	tsurara.WithRetry(tsurara.DefaultRetry()),
	tsurara.WithAuth(func(s tsurara.SecurityUse, _ tsurara.OperationInfo) (string, bool) {
		if s.Scheme == "api_key" {
			return os.Getenv("API_KEY"), true
		}
		return "", false
	}),
)

pet, err := api.GetPetByID(ctx, c, 1, nil)
var failure *tsurara.Failure[api.Problem]
switch {
case err == nil:
	fmt.Println(pet.Data.Name)
case errors.As(err, &failure) && failure.Kind == tsurara.KindHTTP && failure.Documented:
	fmt.Println(failure.Body.Message) // the documented error body
default:
	return err
}
```

## Results

A success status of the definition returns `*Success[T]` with `Status`, `Data`, `Headers` and `Operation`. Everything else returns a `*Failure[E]` as the `error`:

| `Kind` | When |
|---|---|
| `KindHTTP` | An error status: `Documented` and `Body` (type `E`) for a documented status, `Raw` (a `Payload`) otherwise, also for a 2xx when other successes are documented |
| `KindNetwork` | The transport failed (`Cause`) |
| `KindTimeout` | The client's timeout or the context's deadline passed, over all attempts |
| `KindParse` | The body does not match the definition (Content-Type, JSON, the type) |
| `KindUnexpected` | The input cannot be sent (a path parameter that would change the path, a value that does not encode) |
| `KindAborted` | The context was cancelled; `errors.Is(err, context.Canceled)` |

`Failure` unwraps to its cause. To handle the failures of several operations in one place, use `tsurara.AnyFailure`, which every `*Failure[E]` implements:

```go
var f tsurara.AnyFailure
if errors.As(err, &f) {
	info := f.Info() // Kind, Status, Documented, Headers, Cause, Operation
	log.Printf("%s: %s %d", info.Operation.ID, info.Kind, info.Status)
}
```

### Streams

`tsurara.DoItems[T, E]` reads a success item by item (`parseAs` `events`, `jsonLines` or `jsonSeq`): it returns once the headers have arrived, with `*tsurara.Items[T]` as `Data`.

```go
s, err := api.Stream(ctx, client, nil)
if err != nil {
	return err
}
for event, err := range s.Data.All() {
	if err != nil {
		return err
	}
	if n := event.StreamNoteEvent; n != nil {
		fmt.Println(n.Data.ID)
	}
}
```

Reading stops at the first error (a broken connection, or an item that is not valid JSON or does not match `T`). Leaving the loop closes the response, and `Close` closes it without reading. The timeout covers sending and the headers, not the wait for items; cancel `ctx` to end the stream. The client sends every request with `SendStream` when the transport is a `StreamTransport`, as `HTTPTransport` is; a transport with only `Send` hands over the whole body at once.

## Options

| Option | |
|---|---|
| `WithTransport`, `WithHTTPClient` | Another `Transport`, or an `*http.Client` for the default one. The default follows redirects within the origin of the request only (a redirect to another origin is the result, spec/README.md); an `*http.Client` you pass follows its own `CheckRedirect` |
| `WithHeader` | A header for every request |
| `WithTimeout` | Over all attempts of a call; a generated function's options have a `Timeout` per call |
| `WithRetry` | `DefaultRetry()`: idempotent methods, network failures and 408, 429, 500, 502, 503, 504, up to 2 retries, `Retry-After` honored, otherwise backoff with jitter |
| `WithAuth` | The credential for a security scheme of the operation; placed by the scheme (API key header, query or cookie, `Authorization: Bearer`, `Basic` for `user:password`) |
| `OnUndocumentedStatus`, `OnResult` | Observation hooks |

## Testing without a server

Package `tsuraratest` has a `tsurara.Transport` that answers from handlers routed by operation (spec/README.md, Mock transports):

```go
m := tsuraratest.NewMockTransport(
	tsuraratest.Path("GET", "/pets/{petId}", func(r *tsuraratest.Request) (*tsuraratest.Response, error) {
		return tsuraratest.JSON(200, api.Pet{Name: "Pochi"}), nil
	}),
).WithBasePath("/v1")
c := tsurara.NewClient("https://api.test/v1", tsurara.WithTransport(m))
// ... call generated functions, then inspect m.Calls()
```

`tsuraratest.Operation(def, handler)` routes by an OperationDef. A handler error, and a request no route matches, are `KindNetwork` failures; with `RecordUnmatched()`, unmatched requests are answered with 501 and kept in `m.Unmatched()`.

## Installing

```sh
go get github.com/tsurara-openapi/tsurara/runtimes/go
```

Use the version of the generator's release: the module is tagged `runtimes/go/v<version>` with every release of tsurara.

## Development

```sh
go -C runtimes/go test -race ./...
go -C runtimes/go vet ./...
gofmt -l runtimes/go
```
