# tsurara

tsurara generates types and one call function per operation from an OpenAPI definition. The generated code calls a small runtime (`@tsurara/client`, `tsurara-client` for Python and Rust, `github.com/tsurara-openapi/tsurara/runtimes/go`). `tsurara.config.yaml` lists the targets: input definition, output directory, language and options.

## Rules

1. Never edit generated files. They start with a marker (`// Generated by tsurara. Do not edit.`, `# Generated by tsurara. Do not edit.`, `// Code generated by tsurara. DO NOT EDIT.`). Change the definition or `tsurara.config.yaml`, then run `tsurara generate`.
2. Call the generated function for an endpoint; do not build URLs or `fetch` requests by hand. Find it with `tsurara inspect operations --search "<words>"` or the MCP tool `search_operations`, then `tsurara inspect operation <id>` (or `describe_operation`) for its parameters and a call example that compiles.
3. Use what else is generated for the operation instead of writing it: TanStack Query options, keys and filters, and mock handlers and factories for tests. `inspect operation` lists them under "also generated" (`helpers` in JSON).
4. Calls return a Result instead of throwing (except Rust and Go, which return `Result`/`error` as the language does). Check success before using the data; use `unwrap` where an exception is the right failure.
5. Run `tsurara check` before finishing. It fails when generated files are stale or edited, or the runtime version does not match.
6. `tsurara generate` prints warnings with a code and a JSON Pointer into the definition; `tsurara inspect warning <code>` explains each and how to fix it.

## Finding answers

| Question | Command (add `--format json` to parse it) | MCP tool |
|---|---|---|
| Which targets and languages? | read `tsurara.config.yaml` | `list_targets` |
| Which function calls `GET /pets/{id}`? | `tsurara inspect operations --search "get pet"` | `search_operations` |
| How do I call it? | `tsurara inspect operation getPetById --target <name>` | `describe_operation` |
| What does the type `Pet` look like? | `tsurara inspect schema Pet --target <name>` | `describe_schema` |
| What does warning `renamed` mean? | `tsurara inspect warning renamed` | `explain_warning` |
